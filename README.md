# My Daily Frequencies

Proyecto personal que relaciona mi rutina semanal con mi historial de escucha de Spotify (27 de octubre de 2025 – 27 de octubre de 2026).

## Cómo verlo
Abre `index.html` en el navegador con conexión a internet (carga Inter, GSAP y Lenis desde CDN y usa el reproductor de Spotify). También se puede publicar con GitHub Pages desde la rama `main`.

## Apartados
Portada · Rutina · Escuchas (cifras y 12 canciones) · Franjas · Artistas · Constancia · Contacto.

## Archivos
- `index.html`, `style.css`, `script.js`: la web.
- `img/portadas/`: portadas de las 12 canciones (`01.jpg` … `12.jpg`, mismo orden que en la web).
- `log.md`, `contexto.md`, `memoria.md`, `personalidad.md`: notas de trabajo del proyecto.
- El PDF de la entrega de investigación.

## Datos
Las cifras de la web están calculadas a partir del historial de Spotify y escritas directamente en el HTML. Los archivos originales de Spotify **no** se incluyen en el repositorio porque contienen datos personales (pagos, identidad, mensajes).
