# My Daily Frequencies

Proyecto personal que relaciona mi rutina semanal con mi historial de escucha de Spotify (27 de octubre de 2025 – 27 de octubre de 2026). Esta carpeta recoge la web y el proceso con el que se ha construido.

**Web publicada:** https://verablanch.github.io/projectepersonal/ (disponible cuando se active GitHub Pages; pasos en `INSTRUCTIONS.md`).

## Qué hay aquí
| Qué | Dónde |
|---|---|
| La base del proyecto | `SOUL.md`, `CONTEXT.md`, `INSTRUCTIONS.md`, `LOG.md` (y `memoria.md`) |
| Las fichas del loop (una por scroll) | `fichas/` |
| La web | `index.html`, `style.css`, `script.js`, `img/portadas/` |
| Entrega de investigación | el PDF de la raíz |

## Cómo seguir y repetir el proceso
1. Lee `SOUL.md`, `CONTEXT.md` e `INSTRUCTIONS.md`.
2. Mira `LOG.md` de abajo arriba para ver cómo se fue construyendo.
3. Abre las fichas de `fichas/` para ver cada scroll: qué decidió Vera y quién verificó.
4. Los pasos para repetirlo con otros datos están en `INSTRUCTIONS.md`.

## Ver la web en local
Abre `index.html` en el navegador con conexión a internet (carga Inter, GSAP y Lenis desde CDN y usa el reproductor de Spotify).

## Datos
Las cifras de la web están calculadas a partir del historial de Spotify y escritas en el HTML. Los archivos originales **no** se incluyen en el repositorio porque contienen datos personales (pagos, identidad, mensajes).
