# Contexto del proyecto

## Repositorio
Este repositorio, `verablanch/projectepersonal`, es el espacio de referencia para organizar el trabajo y conservar el contexto entre sesiones.

## Objetivo de este sistema
Mantener una base de información clara y actualizada para que cada sesión pueda continuar el trabajo anterior sin perder decisiones, criterios ni avances.

## Archivos principales
- `personalidad.md`: define cómo debe colaborar el asistente y cómo debe comunicarse.
- `contexto.md`: recoge el marco general y el propósito del repositorio.
- `memoria.md`: conserva información estable, decisiones importantes y aprendizajes.
- `log.md`: registra cronológicamente las sesiones de trabajo.

## Criterio de actualización
No asumir información que no esté confirmada. Cuando cambie el objetivo o el alcance del proyecto, actualizar este archivo. Mantener las decisiones vigentes diferenciadas de las ideas provisionales.

## Estado inicial
La estructura de documentación se ha creado para establecer un sistema de continuidad. El contenido específico y los objetivos detallados del proyecto se irán completando a medida que se trabaje en él.
